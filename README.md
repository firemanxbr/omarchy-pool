# v1-screenshots

This branch holds only screenshots: the images that pull requests of the v1.0
redesign (#238) show in their descriptions. Each issue has a directory of its
own (`<issue>/<page>-<theme>-<width>.png`), and a pull request body links the
files through raw.githubusercontent.com.

It shares no history with `main`. Nothing here is built, tested or deployed,
and pushing it runs no workflow. The screenshots are taken from a local
preview of the Worker seeded with the test fixture, never from production.
