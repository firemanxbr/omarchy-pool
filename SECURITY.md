# Security

**Report a vulnerability privately** to the maintainers listed on the
dashboard's [Governance](https://omarchy-pool.firemanxbr.org/docs/governance#maintainers)
page, or open a GitHub security advisory on this repository; please do not
file a public issue for it.

The security model — who may do what, where the keys live, what a
compromised piece can and cannot do — is documented where it runs:
**https://omarchy-pool.firemanxbr.org/docs/security-model** (its source is
[`worker/src/docs/security-model.md`](worker/src/docs/security-model.md),
changed by pull request like anything else).
